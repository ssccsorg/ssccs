# The POC's development record

The POC is the layer the projects materialize, so its record lives beside its code rather than in the published
corpus. Each entry states where a part of the POC stands: what it does, what it does not, and the evidence, and the
subject is the state rather than the work that produced it.

The published documents are elsewhere: the whitepaper under `docs/whitepaper/`, the website under `docs/`, and the
per-crate reference that `doc.py` writes into `_llms/`.
