# Scheme–Segment Composition Computing System (SSCCS)

SSCCS (Scheme–Segment Composition Computing System) is an observation-driven computing model that defines deterministic computation as the realization of structured potential under dynamic constraints. The model treats time as one axis of a multi-dimensional space, replaces instruction sequencing and state mutation with the observation of a declared structure, and shifts the compiler's role from translating code to optimizing the topology of data movement. It provides structural isolation against interference and lossless interpretation through a geometric manifold.

For the philosophical foundation and technical specification, see the Whitepaper [PDF](https://ssccs.org/wp) [HTML](https://ssccs.org/wpw).

## Proof of Concept

The proof of concept materializes one observation pipeline on three substrates and pins them with a shared set of golden anchors. A Rust reference implements the ontology, a branchless RISC-V assembly implementation runs under Spike, and a SystemVerilog implementation runs under Verilator and on an iCESugar-Pro ECP5 board. An independent verifier, `ev` (ExaVerif), reproduces the anchors from its own engine.

![The three substrates and the independent verifier, pinned by the golden anchors](poc/visuals/out/graphviz/architecture.png)

The XIF coprocessor accepts a custom RISC-V instruction, evaluates a constraint or projector, and returns a 64-bit result. The timing diagram is read from `poc/baremetal_riscv/sv/ssccs_xif_coprocessor.sv`. The state machine holds in `XIF_ACCEPT` while the consumer is not ready and spends one cycle in `XIF_RESPOND`.

![XIF coprocessor issue and result handshake](poc/visuals/out/wavedrom/xif_handshake.png)

Each unit lowers to a small schematic. `ck_range` is a signed range check, `proj_sum2d` is an adder, and `compose_product_2d` joins two constraint results. The images are generated by `poc/visuals/gen.sh` from the SystemVerilog units and two text sources, and the POC CI renders them on every change to the units or the visual sources.

![The ck_range constraint lowered to two comparators and an AND gate](poc/visuals/out/netlist/ck_range.png)

See [poc/README.md](/poc/README.md) for the full API, the target status, and the per-substrate build instructions.

```bash
cd poc/standard
cargo build --release --workspace
cargo test --workspace

cd ../baremetal_riscv
cargo build --release
make -C sv check
```

The full validation runs the workspace checks, the assembly syntax gate, the SystemVerilog checks, and the golden anchors. The CI container adds Spike and the RISC-V toolchain.

```bash
cd poc
./run.sh --validation
```

## Documentation

The SSCCS documentation suite consists of several formal documents:

- [Whitepaper](https://ssccs.org/wp): The core technical specification, available as PDF and HTML.
- [Project Direction](/docs/direction/index.qmd): Strategic orientation and regional engagement for the SSCCS initiative.
- [Manifesto](/docs/axioms/manifesto.qmd): The high-level philosophical and technical introduction.
- [Guide](/docs/axioms/ssccs.qmd): A comprehensive guide to SSCCS core concepts.
- [Legal documents](/docs/legal/index.qmd): The foundation's charter and statutes.
- [Research notes](/docs/research/): Informal technical explorations.

All major documents are authored in Quarto (`.qmd`) and can be rendered to PDF, HTML, and Markdown using the SDBS (SSCCS Documentation Build System). SDBS handles Quarto rendering, C2PA signing for PDFs, and output management with caching and parallel execution. See the [SDBS repository](https://github.com/ssccsorg/sdbs) for setup instructions and usage documentation.

## Governance

The SSCCS Initiative is an open-source foundation (in formation) that holds the intellectual property, manages the trademark, and oversees the standardization process. The foundation's charter keeps the project open, neutral, and aligned with its mission of creating a verifiable, sustainable computational commons.

All technical decisions are made through open RFCs and consensus among maintainers. The foundation's statutes guarantee that no single corporation or individual can control the direction of the architecture.
